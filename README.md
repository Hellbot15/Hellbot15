**The Rizvi Exchange — a student-focused marketplace**

A campus marketplace designed around the simple idea of making it easier for students to **buy, sell and exchange items within their college community**.

```text
STUDENT
   │
   ├── 📦 CREATE LISTING
   │
   ├── 🔎 DISCOVER ITEMS
   │
   ├── 🤝 CONNECT
   │
   └── 🔄 BUY / SELL / EXCHANGE
```

**Core capabilities**

* 🛍️ Student item listings
* 🔎 Product discovery
* 🔄 Buying & selling
* 🤝 Campus exchange
* 🔌 REST API architecture
* 📦 Sample data initialization
* 🐳 Docker-ready backend

**Stack**

`React` `Vite` `Java` `Spring Boot` `Spring Data JPA` `H2` `REST API` `Docker`
